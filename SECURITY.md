# Security and data

The bundled lab is a local synthetic teaching app. It binds loopback only and deliberately lets the learner choose a role. It is not a production authentication system. Do not deploy it publicly.

Do not commit tokens, `.env`, browser state, real records or customer screenshots. This starter has no telemetry or outbound application requests. Package/driver/browser installation contacts upstream distribution services.

For sensitive reports, use GitHub private vulnerability reporting if enabled; otherwise contact ContextQA through https://contextqa.com/ without putting exploit details or secrets in a public issue.
